인증 서비스에 들어온 요청
Cookie, 전달된 원 host/URI/method와 판정 요청의 실제 method. TrustedProxies는 tinyauth의 client IP 판단을 설정한다.
보호 앱에 들어온 요청
앱이 신원으로 쓰는 헤더 전체와 직접 접근 경로. authResponseHeaders의 관리 범위는 이름별로 확인한다.
브라우저에 돌아온 응답
이동이면 Location, 성공한 요청이면 앱 응답. 갱신 시 인증 응답과 최종 응답의 Set-Cookie를 대조한다.

세션과 장애의 관측 지점

  • 브라우저는 Domain·Path 등 전송 조건을 따른다. 중앙 host-only cookie와 각 앱 세션의 종료 효과는 각각 확인한다. 0059 SSO 범위 · RFC 6265 §5.4
  • 갱신은 DB expiry, 인증 응답, 최종 응답, 브라우저 저장을 비교한다. 로그아웃 후 재방문은 화면 상태를, UUID의 행 조회는 서버 폐기를 보여 준다. 0060 수명과 폐기 · tinyauth @6dfdcf0
  • 인증 서비스 응답 유무, proxy 오류 로그, 앱 도달 건수를 같은 요청에서 비교한다. Envoy ext_authz 기본 장애 응답도 403일 수 있다. 0061 장애 · Envoy 설정

OIDC 서명 검증 지점

등록 callback에 code가 도착한다. RP 백엔드가 교환하고 신뢰한 issuer의 jwks_uri에서 kid에 맞는 공개 키를 사용한다. RS256 서명과 iss, aud, exp, 보낸 경우 nonce를 확인한다. 0062 선택 OIDC/JWKS · OIDC Core §3.1.3.7
