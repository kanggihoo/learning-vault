Kafka Consumer & Group 설정 치트시트

실제 설정 시 참고용 — 전체 목록은 공식 문서 Group Configs와 Consumer Configs 참고. 사고 방식은 0027 레슨 참고.

1. Group Configs (브로커 쪽 가드레일)

설정기본값메모
group.min.session.timeout.ms6000Consumer가 요청 가능한 session timeout 최소값
group.max.session.timeout.ms1800000최대값 (30분)
consumer.session.timeout.ms45000신규 Consumer Group Protocol에서 브로커가 강제하는 세션 타임아웃
consumer.heartbeat.interval.ms5000신규 프로토콜의 하트비트 간격(브로커 강제)
consumer.assignment.interval.ms1000신규 프로토콜에서 할당이 갱신되는 간격
share.session.timeout.ms45000Share Group 프로토콜 세션 타임아웃
share.heartbeat.interval.ms5000Share Group 하트비트 간격
share.record.lock.duration.ms30000Share Group의 기본 acquisition lock 유지 시간(브로커 상한)
share.partition.max.record.locks2000공유 파티션 하나당 동시 lock 최대 개수
share.delivery.count.limit5같은 레코드 최대 재전달 시도 횟수
share.isolation.levelread_uncommittedShare Group의 트랜잭션 격리 수준(브로커 쪽 기본값)
streams.session.timeout.ms / streams.heartbeat.interval.ms45000 / 5000Kafka Streams 그룹 전용, 패턴은 동일
streams.num.standby.replicas0Streams 태스크의 대기 복제본 수

2. 그룹 멤버십 / 장애 감지 (Consumer, classic 프로토콜)

설정기본값메모
session.timeout.ms45000group.protocol=consumer일 땐 미적용(브로커 값 사용)
heartbeat.interval.ms3000session.timeout의 1/3 이하 권장, consumer 프로토콜에선 미적용
max.poll.interval.ms300000 (5분)poll() 미호출 시 그룹에서 제외 트리거
group.instance.idnull값을 주면 Static Membership 활성화
group.protocolclassicconsumer로 바꾸면 신규 rebalance 프로토콜 사용
group.remote.assignornullconsumer 프로토콜에서 서버 측 할당자 지정
partition.assignment.strategyRangeAssignor, CooperativeStickyAssignorclassic 프로토콜의 할당 전략 목록(우선순위 순)

3. 어디서부터, 언제 커밋

설정기본값메모
auto.offset.resetlatestearliest / none / by_duration:… 선택 가능
enable.auto.committruefalse면 직접 커밋 필요(at-least-once 정확도↑)
auto.commit.interval.ms5000auto commit 주기
isolation.levelread_uncommittedread_committed면 트랜잭션 커밋 마커까지 반영해 필터링
allow.auto.create.topicstrue구독 대상 토픽 자동 생성 허용 여부(브로커의 auto.create.topics.enable도 필요)

4. Fetch 튜닝 (지연 vs 처리량)

설정기본값메모
fetch.min.bytes1이만큼 쌓일 때까지 응답 지연
fetch.max.wait.ms500fetch.min.bytes 미충족 시 최대 대기
fetch.max.bytes52428800 (50MB)fetch 요청 전체의 최대 반환량(절대 상한 아님)
max.partition.fetch.bytes1048576 (1MB)파티션별 최대 반환량
max.poll.records500poll() 한 번에 반환되는 최대 레코드 수

5. Share Consumer 전용 (Client 설정)

설정기본값메모
share.acknowledgement.modeimplicitexplicit이면 acknowledge() 직접 호출 필요
share.acquire.modebatch_optimizedrecord_limit이면 max.poll.records 엄격히 준수
