Kafka Admin Client 설정 치트시트

AdminClient에서 실제로 특이한 설정만 정리했다. bootstrap.servers, security.protocol, ssl.*, sasl.*, retries, retry.backoff.ms, request.timeout.ms, client.id 같은 공통 client 설정은 Producer 설정 치트시트 참고 — Producer/Consumer/AdminClient가 전부 공유한다. 전체 목록은 공식 문서 AdminClient Configs. 사고 방식은 0030 레슨 참고.

1. AdminClient 전용 연결 설정

설정기본값의미
bootstrap.servers""Broker에 연결(토픽 관리 등 일반 관리 작업)
bootstrap.controllers""KRaft Controller quorum에 직접 연결(quorum 상태 확인 등)

2. API 호출 전체의 기한

설정기본값의미
default.api.timeout.ms60000 (1분)호출 시 timeout을 안 주면 적용되는, 재시도 포함 API 호출 전체의 최종 기한. 요청 하나의 응답 대기 시간(request.timeout.ms)과는 다른 개념

3. 운영 시 조심할 것 (설정이 아니라 사용 패턴)

상황주의
토픽 생성 요청 재시도실제로는 첫 요청이 성공했는데 응답만 못 받아 재시도되면 TopicExistsException이 날 수 있음 — 진짜 실패가 아닐 수 있으니 자동화 코드에서 구분해서 처리

공식 자료
