Kafka 모니터링 핵심 지표 치트시트

실제 알림 설정 시 참고용 — 전체 목록(수백 개)은 공식 문서 Monitoring 참고. 사고 방식은 0023 레슨 참고.

1. 클러스터/컨트롤러 상태 (무조건 알림)

지표Mbean정상값
Under-replicated partitionskafka.server:type=ReplicaManager,name=UnderReplicatedPartitions0
Under min ISR partitionskafka.server:type=ReplicaManager,name=UnderMinIsrPartitionCount0
Offline replica 수kafka.server:type=ReplicaManager,name=OfflineReplicaCount0
Offline partition 수kafka.controller:type=KafkaController,name=OfflinePartitionsCount0
Active controller 수kafka.controller:type=KafkaController,name=ActiveControllerCount클러스터 합계 1
Unclean leader election ratekafka.controller:type=ControllerStats,name=UncleanLeaderElectionsPerSec0
Leader election ratekafka.controller:type=ControllerStats,name=LeaderElectionRateAndTimeMs브로커 장애 시에만 non-zero
Offline log directory 수kafka.log:type=LogManager,name=OfflineLogDirectoryCount0
ISR shrink / expand ratekafka.server:type=ReplicaManager,name=Isr{Shrinks|Expands}PerSec평상시 0 (브로커 재기동 전후엔 잠깐 변동 정상)
Failed ISR update ratekafka.server:type=ReplicaManager,name=FailedIsrUpdatesPerSec0

2. 브로커 처리량·지연

지표Mbean메모
요청 총 시간kafka.network:type=RequestMetrics,name=TotalTimeMs,request={Produce|FetchConsumer|FetchFollower}Queue/Local/Remote/Response 4단계로 세분 가능
Queue 대기 시간...,name=RequestQueueTimeMs,...커지면 스레드 포화
Local 처리 시간...,name=LocalTimeMs,...커지면 디스크 I/O 지연
Remote 대기 시간...,name=RemoteTimeMs,...acks=-1일 때만 non-zero, 커지면 Follower 지연
Response 전송 시간...,name=ResponseSendTimeMs,...커지면 네트워크 포화
Request handler idle %kafka.server:type=KafkaRequestHandlerPool,name=RequestHandlerAvgIdlePercent0.3 이상 권장
Network processor idle %kafka.network:type=SocketServer,name=NetworkProcessorAvgIdlePercent0.3 이상 권장
Request queue 크기kafka.network:type=RequestChannel,name=RequestQueueSize계속 쌓이면 처리 지연
Produce/Fetch purgatory 크기kafka.server:type=DelayedOperationPurgatory,name=PurgatorySize,delayedOperation={Produce|Fetch}대기 중인 요청 수 — acks=-1/fetch.wait.max.ms에 영향받음
Message/Byte in-out ratekafka.server:type=BrokerTopicMetrics,name={Messages|Bytes}{In|Out}PerSec토픽별 트래픽 추세 파악용
Log flush 시간kafka.log:type=LogFlushStats,name=LogFlushRateAndTimeMspage cache → disk 반영 시간

3. 그룹 코디네이터 (Consumer Group)

지표Mbean메모
상태별 group 수kafka.server:type=group-coordinator-metrics,name=consumer-group-count,state=[empty|assigning|reconciling|stable|dead]stable 아닌 상태가 오래 지속되면 rebalance 걸림 의심
Rebalance rate/count...,name=consumer-group-rebalance-{rate|count}너무 잦으면 Static Membership(0019) 고려
Offset commit rate...,name=offset-commit-rate급감하면 consumer가 멈춘 신호
Partition load time (max/avg)...,name=partition-load-time-{max|avg}__consumer_offsets 파티션 로딩 지연

4. Producer/Consumer 클라이언트 공통

지표Mbean메모
Consumer lagkafka.consumer:type=consumer-fetch-manager-metrics,client-id={id} attr records-lag-max가장 중요 — 계속 증가 추세인지가 핵심
Request/Response ratekafka.[producer|consumer]:type=[producer|consumer]-metrics,client-id=(...) attr request-rate/response-rate급감 시 클라이언트 정지 의심
Error rate (per type/code)kafka.network:type=RequestMetrics,name=ErrorsPerSec,request=(...),error=(...)error=NONE은 성공, 나머지 합이 0이 정상
Throttle timekafka.server:type={Produce|Fetch},user=(...),client-id=(...) attr throttle-timeQuota(0019)에 걸려 지연된 시간, 0이 정상
Connection countattr connection-count급증/급감 이상 여부 확인용

5. KRaft 쿼럼 (KRaft 모드 전용)

지표메모
Current State (leader/candidate/follower/...)kafka.server:type=raft-metrics
Fenced/Active broker 수kafka.controller:type=KafkaController,name={Fenced|Active}BrokerCount
Last Applied Record Lag Mscontroller/broker가 최신 metadata를 얼마나 뒤처져 반영하는지, 0에 가까울수록 정상
Timed-out broker heartbeat 수kafka.controller:type=KafkaController,name=TimedOutBrokerHeartbeatCount, 늘어나면 broker가 응답 없음
