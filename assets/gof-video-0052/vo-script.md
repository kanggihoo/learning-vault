# VO 대본 — GoF 4/6 Composite · Facade · Bridge · Flyweight (68초)

한 문단 = 한 장면. 문단 사이 1초쯤 쉰다.

1. (0–8초) 구조 패턴 네 개. 모양보다 먼저, 각자 어떤 질문에 답하는지 보세요. 트리로 묶기, 창구 하나, 두 갈래로, 공유로 아끼기.

2. (8–19초) Composite는 부분과 전체를 똑같이 다룹니다. 객실도, 층도, 호텔도 같은 count를 부르고, 가지는 자식들의 결과를 더합니다. 자기와 같은 타입의 목록을 들고 있으면 Composite입니다.

3. (19–31초) Facade는 단순한 창구입니다. 손님은 컨시어지에게 한 번만 부탁하고, 식당, 택시, 공연은 창구가 순서대로 처리합니다. 그래도 식당에 직접 가는 길은 막지 않습니다.

4. (31–45초) Bridge는 두 갈래로 쪼갭니다. 리모컨과 TV를 따로 늘리고, device 필드라는 다리로 잇습니다. 상속만 쓰면 조합마다 클래스가 생겨 곱하기로 늘지만, 쪼개면 더하기로 늡니다.

5. (45–57초) Flyweight는 공유로 아낍니다. 나무 만 그루가 모델을 각자 들면 10기가, 같은 모델 하나를 공유하면 1메가입니다. 공유하는 모델은 내재 상태, 그루마다 다른 위치는 외재 상태입니다.

6. (57–68초) 정리하면, 트리로 같게 다루면 Composite, 단순 창구면 Facade, 두 계층을 쪼개면 Bridge, 공유로 아끼면 Flyweight.
