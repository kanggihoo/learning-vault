# VO 대본 — GoF 5/6 Iterator · Visitor · Memento · Interpreter (64초)

한 문단 = 한 장면. 문단 사이 1초쯤 쉰다.

1. (0–6초) 이번 네 패턴은 서로 닮은 쌍이 아닙니다. 각자 다른 질문 하나에 답합니다. 꺼내기, 연산 추가, 되돌리기, 해석.

2. (6–18초) Iterator는 속을 몰라도 하나씩 꺼냅니다. 상자 안이 리스트든 트리든 해시든, hasNext로 남았는지 묻고 next로 하나씩 꺼내면 됩니다. 다 꺼내면 hasNext가 false가 되어 멈춥니다.

3. (18–32초) Visitor는 집은 그대로 두고 연산이 방문합니다. 집은 accept 하나만 열어 두고, 방문자가 visit으로 각 집에 맞는 일을 합니다. 새 연산은 방문자를 하나 더 만들면 끝. 대신 새 집 종류가 생기면 모든 방문자를 고쳐야 합니다.

4. (32–42초) Memento는 저장했다가 되돌립니다. 집이 자기 상태를 봉투에 담아 내주면, Caretaker는 열어 보지 않고 쌓아 두기만 합니다. 되돌릴 때는 봉투를 다시 주인에게 돌려줍니다.

5. (42–52초) Interpreter는 문법을 트리로 해석합니다. 1 더하기 2, 곱하기 3을 Mul, Add, Num 객체의 트리로 세우고, 루트에서 interpret를 부르면 3, 그리고 9가 나옵니다.

6. (52–64초) 정리하면, 하나씩 꺼내면 Iterator, accept와 visit으로 연산을 빼면 Visitor, 상태를 저장하고 복원하면 Memento, 문법 트리를 해석하면 Interpreter. 질문이 패턴을 고릅니다.
