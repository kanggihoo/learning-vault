# VO 대본 — GoF 6/6 생성 패턴 5개 (75초)

한 문단 = 한 장면. 문단 사이 1초쯤 쉰다.

1. (0–8초) 생성 패턴은 한 가지 질문에 답합니다. 객체를 어떻게 만들까? 만드는 방법은 다섯 가지입니다.

2. (8–21초) Factory Method. 부모 Bakery는 createBread를 비워 둡니다. 강남점은 식빵을, 부산점은 바게트를 굽죠. 무엇을 만들지 상속받은 자식이 정합니다.

3. (21–32초) Abstract Factory. 오븐에 모던 공장을 걸면 의자, 소파, 탁자가 어울리는 세트로 한 번에 나옵니다. 공장 하나를 클래식으로 바꾸면 세트 전체가 바뀝니다.

4. (32–44초) Builder. 인자가 다섯 개인 생성자는 어떤 값이 무엇인지 읽을 수 없습니다. 그래서 size, cheese, pepperoni를 이름 붙여 하나씩 채우고, 마지막에 build로 완성품을 받습니다.

5. (44–54초) Prototype. new로 처음부터 만들지 않고, 이미 있는 객체를 copy로 복제합니다. 실제 클래스를 몰라도 되고, 복사본을 조금만 고쳐 쓰면 됩니다.

6. (54–63초) Singleton. 생성자는 private으로 잠겨 있고, getInstance를 몇 번 불러도 같은 하나가 돌아옵니다. 그래서 카운터는 세 번 부르면 3이 됩니다.

7. (63–75초) 정리하면, 상속으로 한 제품이면 Factory Method, 제품군이면 Abstract Factory, 단계별이면 Builder, 복제면 Prototype, 하나뿐이면 Singleton. 코드 모양이 이름을 말해 줍니다.
