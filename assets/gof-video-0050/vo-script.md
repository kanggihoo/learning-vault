# VO 대본 — GoF 2/6 Decorator · Proxy · Adapter (60초)

한 문단 = 한 장면. 문단 사이 1초쯤 쉰다.

1. (0–7.6초) Adapter, Decorator, Proxy. 셋 다 원본 객체를 필드로 들고 감싸는 래퍼라서 코드 모양이 거의 같습니다. 그래서 신호 두 개로 가릅니다. 감싼 뒤 인터페이스가 같은가, 그리고 원본을 어떻게 부르는가.

2. (7.6–19초) Adapter는 모양을 맞춥니다. 클라이언트는 Printer 모양을 기대하는데 OldPrinter는 구멍 모양이 달라 꽂히지 않죠. 어댑터가 바깥은 Printer로, 안쪽은 OldPrinter로 바꿔서 이어 줍니다. 감싼 뒤 인터페이스가 달라지는 건 Adapter뿐입니다.

3. (19–30.5초) Decorator는 인터페이스가 같은 채로 기능을 겹겹이 얹습니다. 클라이언트가 에스프레소에 우유, 그 위에 휘핑을 쌓으면, 호출은 항상 원본까지 갔다가 돌아오면서 오백 원씩 더합니다. 원본은 항상 부릅니다.

4. (30.5–45초) Proxy도 인터페이스는 같지만, 원본을 부를지 말지, 언제 만들지를 스스로 정합니다. 권한이 없으면 거절하고, 처음 필요할 때에야 원본을 만듭니다. 그리고 @Transactional처럼 클라이언트가 아니라 프레임워크가 만들어 끼운 래퍼도 Proxy입니다.

5. (45–60초) 정리하면, 인터페이스가 달라지면 Adapter. 같다면 원본을 어떻게 부르는지 보세요. 항상 부르며 얹으면 Decorator, 부를지·언제 만들지 정하면 Proxy.
