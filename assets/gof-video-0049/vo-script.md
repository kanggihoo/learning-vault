# VO 대본 — GoF 1/6 Strategy · State · Template Method (60초)

한 문단 = 한 장면. 문단 사이 1초쯤 쉰다.

1. (0–9초) Strategy, State, Template Method. 셋 다 if나 switch로 나누던 동작을 클래스로 빼낸 패턴이라 모양이 닮았습니다. 구분 신호는 두 개. 상속인가 합성인가, 그리고 누가 갈아끼우는가.

2. (9–23초) Strategy는 밖에서 갈아끼웁니다. 내비게이션 본체는 그대로 두고, 운전자가 최단 경로를 꽂았다가 무료 경로로 바꿔 끼우죠. setStrategy 한 줄이면 실행 중에도 바뀝니다.

3. (23–37초) State는 안에서 스스로 바뀝니다. 자판기는 같은 버튼을 눌러도 상태에 따라 다르게 움직입니다. 음료를 내준 '동전 있음' 상태가 직접 '동전 없음'을 만들어 다음 상태로 넘깁니다. 아무도 손대지 않았는데요.

4. (37–49초) Template Method는 상속입니다. 물 끓이기, 면, 스프, 먹기. 순서는 부모 클래스가 final로 고정하고, 비어 있는 스프 단계만 자식 클래스가 채웁니다. 컴파일 때 정해지니 실행 중에는 바꿀 수 없습니다.

5. (49–60초) 정리하면, 상속이면 Template Method. 합성이면 누가 바꾸는지 보세요. 밖에서 고르면 Strategy, 상태 객체가 스스로 넘어가면 State.
