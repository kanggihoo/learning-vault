# Agent Instructions

정확하고 명확하게 응답한다.

## Project Context

Before working in this repository, read [CONTEXT.md](./CONTEXT.md). Use its language as the source of truth for this Learning Vault.

## Learning Workflow

Use the `teach` skill for Teach Sessions. The `teach` skill's storage structure is the project standard:

- `MISSION.md`
- `RESOURCES.md`
- `NOTES.md`
- `lessons/*.html`
- `reference/*.html`
- `summaries/*.md`
- `learning-records/*.md`
- `assets/*`

Do not create a competing learning storage structure unless the project context is updated first.

## Learning Index

Keep [INDEX.md](./INDEX.md) as the top-level Learning Index.

When a Teach Session creates or updates saved learning material in `lessons/`, `reference/`, `summaries/`, or `learning-records/`, update `INDEX.md` in the same turn with links to the new or changed material.
