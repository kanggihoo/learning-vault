# Kafka 학습 시작 — 실무 도입 목표 기준점

사용자는 백엔드 개발자로서 실제로 Kafka를 도입할 계획이 있으며, 도입 전에 개념과 동작 원리를
제대로 이해하는 것이 목표다. Kafka는 완전히 새로운 학습으로, 처음 배우는 주제라 사전 지식이
없다고 가정하고 시작했다. 다만 [[0020-redis-streams-consumer-group-baseline]]에서 확립된
Redis Streams의 Consumer Group/PEL/XACK/XAUTOCLAIM 이해가 있어, Kafka의 Topic/Partition/
Consumer Group/Offset을 설명할 때 이 지식을 발판(analogy)으로 적극 활용했다. 이는 별도의
새 미션(기존 "분산 백엔드 아키텍처 이해" 미션과는 독립)으로 [[MISSION.md]]에 추가했다.
