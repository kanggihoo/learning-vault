# 아키텍처 어휘 학습 시작 — 지도 우선, 목표는 리뷰·면접 설명력

사용자가 아키텍처 관련 어휘(architecture driver, 품질 속성, 전술, 스타일, 패턴)를 하나로 정리하고 싶다고 요청했다.
2026-09-05 세션에서 미션을 확정했다: **① AI 설계안 리뷰 ② 기술면접 설명력 ③ 용어 정리 자체**가 목적이고,
예시는 **일반 백엔드 시스템**(결제·주문 등 교과서적 사례)으로 들며, 진행은 **지도 먼저 → 레슨**이다.

**Implications**
- [[0030-two-types-of-understanding-and-the-map-gap]]의 교훈을 이번엔 처음부터 적용했다 —
  레슨 0037 이전에 레퍼런스 0020(아키텍처 설계 지도)을 먼저 만들었다. 마켓 리플레이에서 지도를 늦게 만들어 실패했던 것의 교정.
- 예시 기준이 "마켓 리플레이 프로젝트"가 아니라 "일반 백엔드"라는 점이 중요하다.
  이전 미션들과 달리 **전이 가능한 표준 사례**를 쓰되, 이미 배운 것(Kafka·Redis Streams·Outbox·STOMP)과
  만나는 지점만 명시적으로 링크한다.
- 아크 예상: 0037 driver+품질속성 → 전술 → 스타일 → 패턴 → 트레이드오프/평가(ATAM·ADR·C4).
  6~8개 레슨.
